# Business Sales Performance Dashboard

## Project Overview
This project analyzes business sales data using Power BI to identify sales trends, profitable categories, top-performing products, and regional performance.

## Tools Used
- Power BI
- Excel / CSV Dataset
- Data Visualization

## Key Insights
- Technology category generated highest profit
- West region achieved strongest sales
- Top products contribute major revenue

## Dashboard Features
- KPI Cards
- Monthly Sales Trend
- Profit by Category
- Top Products Analysis
- Regional Sales Analysis
